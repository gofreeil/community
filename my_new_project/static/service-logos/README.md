# לוגואים רשמיים לסוגי-שירות (מפה)

תיקייה זו מיועדת לקובצי לוגו **רשמיים** של גופים (בנקים, דואר וכו') שמוצגים
על המפה במקום תג המונוגרם האוטומטי.

## איך משתמשים

1. שמרו כאן את קובץ המותג הרשמי. עדיף **SVG שקוף** (או PNG מרובע עם רקע משלו).
   דוגמה: `hapoalim.svg`, `israel-post.svg`.
2. פתחו את `src/lib/serviceLogoOverrides.ts` והוסיפו שורה שמקשרת בין מזהה
   השירות לקובץ, למשל:
   ```ts
   bank_hapoalim: '/service-logos/hapoalim.svg',
   post:          '/service-logos/israel-post.svg',
   ```
3. שמרו ודחפו. מאותו רגע כל סניף מאותו סוג יציג את הלוגו הרשמי בכל האתר
   (מפה, בורר סוג-שירות, דף הפריט).

מזהי השירות האפשריים (`id`) מוגדרים ב-`src/lib/serviceTypes.ts` תחת הקבוצה
"דואר ובנקאות" ושאר הקבוצות.

## חשוב

השתמשו רק בקבצים שיש לכם זכות שימוש בהם (ערכות מותג רשמיות / אישור מהגוף).
כל עוד לא הוגדר קובץ רשמי, המפה מציגה תג מקורי: עיגול בצבע-המותג + מונוגרם עברי.
